Predicting Customer Churn with Data

Can customer data help us identify who is likely to leave? This project explores churn patterns and proposes a machine-learning workflow to support earlier customer-retention actions.

01 · Research question

How can we predict customer churn?

Customer churn occurs when a customer stops using a service. The goal is to use historical customer attributes to predict the target variable Churn (Yes/No), then identify patterns that may help a business retain customers.

Prediction

Estimate whether a customer is likely to churn using available account and service information.

Explanation

Explore which factors—such as contract type, tenure, charges, and support services—are associated with churn.

Action

Use risk estimates to prioritize retention outreach, while avoiding unfair or unsupported assumptions.

03 · Proposed methods

Compare at least three classifiers

Because Churn is a categorical Yes/No label, this is a supervised binary-classification task. Compare models on the same held-out test set rather than choosing a model by intuition.

01 · Logistic Regression

A clear baseline that estimates churn probability and is relatively easy to interpret.

02 · Decision Tree

Produces understandable decision rules and can reveal combinations of churn-related features.

03 · Random Forest

Combines many trees and can capture more complex patterns, though interpretation is less direct.

How should performance be evaluated?

Confusion matrix

Shows true positives, true negatives, false positives and false negatives.

Precision, Recall and F1

Recall measures how many actual churners are found; precision measures how many flagged customers really churned.

ROC-AUC

Measures how well the model ranks churners above non-churners across thresholds.

Train/test split

Use a stratified split and fit preprocessing only on training data to reduce leakage.

04 · Project workflow

From raw data to useful predictions

1
Understand the data

Check column meanings, class balance, data types, duplicates and missing values.

2
Prepare features

Remove customerID from predictors; encode categorical features and scale numeric values where needed.

3
Split the data

Use a stratified training/test split before model fitting and preprocessing.

4
Train three models

Fit Logistic Regression, Decision Tree and Random Forest on the training set.

5
Evaluate fairly

Compare recall, precision, F1 and ROC-AUC on the same test set.

6
Interpret and recommend

Discuss important features, limitations and realistic retention strategies.
